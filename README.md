# MorseMotion

Веб-приложение для изучения и ввода азбуки Морзе жестами перед веб-камерой.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite, и разрешите браузеру доступ к камере.

## Жесты

| Жест | Действие |
| --- | --- |
| Только большой палец | Точка `·` |
| Только указательный палец | Тире `—` |
| Большой и указательный пальцы | Пробел |
| Открытая ладонь | Завершить и проверить букву |
| Один кулак | Удалить последний сигнал |
| Две открытые ладони | Сбросить сообщение |
| Два кулака | Отправить радиограмму |

Каждый жест должен удерживаться 500 мс. Это защищает от случайных срабатываний.

## Режимы

- **Радиограмма** — свободный набор кириллического сообщения.
- **Тренировка букв** — случайная буква и её код Морзе.
- **Слова** — случайное слово, которое нужно набрать без ошибок.

В тренировке и режиме слов терминал мигает зелёным после верного ответа и красным после неверного.

## Структура кода

- `src/main.ts` — интерфейс, состояние приложения и сценарии режимов.
- `src/morse.ts` — таблица Морзе и функции форматирования кода.
- `src/hand-gestures.ts` — правила распознавания поз пальцев по 21 точке MediaPipe.
- `src/style.css` — стили и анимации интерфейса.

MediaPipe находит точки кисти в браузере. Собственные правила проекта определяют, какие пальцы выпрямлены, собирают точки и тире, а затем переводят их в буквы через таблицу Морзе.
