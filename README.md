# MorseMotion

> Интерактивный тренажёр азбуки Морзе, которым можно управлять жестами перед обычной веб-камерой.

**MorseMotion** помогает освоить азбуку Морзе не через кнопки и клавиатуру, а через движение рук. Пользователь показывает жесты для точки и тире, видит распознанный сигнал в реальном времени и получает понятную обратную связь при ошибке.

Проект создан для кейса **ADMIT HACKATHON: «Камера вместо джойстика»**.

## Зачем нужен MorseMotion

Азбука Морзе обычно изучается через таблицы и ввод с клавиатуры. Это пассивно и не всегда интересно. MorseMotion превращает обучение в короткое визуальное взаимодействие:

1. Пользователь открывает сайт и включает веб-камеру.
2. Показывает жесты пальцами.
3. Приложение распознаёт точку или тире и отображает скелет кисти.
4. Сигналы превращаются в кириллические буквы.
5. Пользователь тренируется на буквах, набирает слова или передаёт собственную радиограмму.

Ничего устанавливать не нужно: приложение работает прямо в браузере.

## Возможности

- Распознаёт движения рук в реальном времени через веб-камеру.
- Показывает точки кисти и соединяющий их скелет поверх видео.
- Закрывает лицо мозаикой прямо в окне камеры; режим можно выключить переключателем.
- Переводит последовательности точки и тире в кириллические буквы.
- Поддерживает свободный ввод собственных сообщений.
- Предлагает тренировку случайных букв.
- Предлагает игру со случайными словами.
- В мини-игре «Эхо эфира» показывает код Морзе на мгновение, а затем проверяет, сможет ли пользователь повторить его по памяти; есть три попытки и личный рекорд.
- Показывает историю отправленных радиограмм до обновления страницы.
- Даёт конкретные подсказки, если поза руки неточная, а при потере трекинга — что поправить в кадре, освещении и расстоянии.
- Подсвечивает результат: зелёная вспышка терминала при верном ответе и красная при ошибке.

## Режимы

### Радиограмма

Свободный режим для набора сообщения кириллицей. После набора каждой буквы пользователь раскрывает ладонь, а две сжатые руки отправляют готовую радиограмму. На экране появляется подтверждение, а сообщение сохраняется в истории текущей сессии.

### Тренировка букв

Приложение показывает случайную букву и её Морзе-код. Пользователь повторяет код жестами. Верный ответ увеличивает счётчик и сразу показывает следующую букву.

### Слова

Приложение выдаёт случайное слово: например, `МОРЗЕ`, `РАДИО`, `СИГНАЛ` или `КАМЕРА`. Пользователь должен набрать его по буквам. Неверная буква не добавляется в результат.

### Эхо эфира

Короткая игра на зрительную память и жестовый ввод: приложение на 1,8 секунды показывает код случайной буквы Морзе, затем скрывает его. Игрок повторяет точки и тире жестами и раскрывает ладонь для проверки. За правильный ответ начисляется очко; три ошибки завершают раунд. Лучший счёт сохраняется в браузере.

### Скорость

Раунд на 1, 2 или 3 минуты с выбором формата: случайные слова или отдельные буквы. После раунда приложение показывает точность, среднее и лучшее время ответа, а также хранит отдельный рекорд для каждой комбинации режима и длительности в браузере.

### Калибровка

Персональная настройка для конкретной руки и положения перед камерой. Перед записью каждого из пяти жестов идёт обратный отсчёт 3 секунды, после чего приложение собирает 24–36 кадров. Образец можно сохранить, когда рука достаточно стабильна. Сохраняются только нормализованные координаты 21 точки скелета кисти, а не фото или видео. Уверенно совпавший образец корректирует общий классификатор, если у пользователя жест выглядит иначе; настройки можно сбросить и записать заново.

## Управление жестами

Каждый жест нужно удерживать **300 мс** и показать одинаковую позу минимум в **5 последовательных кадрах**. Камера запрашивается с частотой до 30 FPS. Это уменьшает случайные срабатывания, но сохраняет быстрый ввод.

| Жест | Действие |
| --- | --- |
| Только большой палец 👍 | Точка `·` |
| Только указательный палец ☝️ | Тире `—` |
| Большой и указательный пальцы ✌️ | Пробел между словами |
| Открытая ладонь ✋ | Завершить и проверить текущую букву |
| Один кулак ✊ | Удалить последний сигнал |
| Две открытые ладони 🙌 | Очистить сообщение |
| Два кулака ✊✊ | Отправить радиограмму |

## Режим ошибки

MorseMotion не ограничивается сообщением «жест не распознан». Приложение проверяет, какие пальцы выпрямлены, угол суставов и положение кисти. При проблеме пользователь получает конкретную подсказку, например:

- «Выпрями большой палец для точки»;
- «Согни лишние пальцы — жест сейчас неоднозначен»;
- «Покажи кисть целиком»;
- «Неверная буква. Сейчас нужна “Р”. Попробуй её код ещё раз».

В тренировке букв и режиме слов терминал мигает **красным** после неверного кода и **зелёным** после верного. Так пользователь сразу понимает результат действия.

## Как это работает

1. Браузер получает видеопоток через `navigator.mediaDevices.getUserMedia`.
2. MediaPipe Hand Landmarker определяет 21 точку на кисти.
3. Собственная логика MorseMotion определяет, какие пальцы подняты и насколько они выпрямлены.
4. Жесты собираются в строку из `.` и `-`.
5. После раскрытой ладони строка ищется в таблице кириллической азбуки Морзе и становится буквой.

Логика распознавания жестов (правила по пальцам и суставам, удержание жеста, защита от повторов) и сценарии написаны автором. Для кулака приложение отдельно проверяет сгибание суставов, чтобы не путать его с частично видимой рукой. Если трекинг теряется дольше 0,8 секунды, приложение советует поднести кисть ближе, повернуть ладонь к камере и проверить освещение. Доработки (калибровка, конкретные подсказки при ошибке, конфигурация, подготовка к деплою, часть интерфейса режима скорости, документация) сделаны с помощью ИИ-агента и проверены автором. MediaPipe локально получает 21 точку кисти и прямоугольник лица для мозаики; фото и видео не покидают браузер. Если GPU недоступен, распознавание рук запускается на CPU.

## Запуск локально

Нужен Node.js 20+.

### Windows: быстрый запуск

Скачайте или клонируйте репозиторий и дважды нажмите [`install.bat`](install.bat). Скрипт сам проверит Node.js и npm, перейдёт в папку проекта и установит версии зависимостей, зафиксированные в `package-lock.json`. Затем выполните:

```bash
npm run dev
```

### Любая ОС: запуск через терминал

```bash
git clone https://github.com/RiazArys/Beibitai_admit_hackathon.git
cd Beibitai_admit_hackathon
npm ci
npm run dev
```

Откройте адрес из терминала, нажмите **«Включить камеру»** и разрешите браузеру доступ к камере. Для работы камеры на деплое потребуется HTTPS.

## Условия для устойчивой работы

Кисть должна целиком попадать в кадр, а освещение — позволять камере различать пальцы. После изменения положения камеры или руки рекомендуется пройти калибровку заново.

## Деплой

Проект подготовлен для Vercel: в [`vercel.json`](vercel.json) уже указан Vite, а результат сборки создаётся в каталоге `dist`.

### Публикация через GitHub и Vercel

1. Убедитесь, что последняя версия проекта находится в ветке `main` GitHub-репозитория.
2. Откройте [vercel.com/new](https://vercel.com/new), войдите через GitHub и нажмите **Add New → Project**.
3. Найдите репозиторий `RiazArys/Beibitai_admit_hackathon` и нажмите **Import**. Если репозиторий не отображается, разрешите Vercel доступ к нему в настройках GitHub.
4. На экране настройки проекта проверьте параметры:

   | Параметр Vercel | Значение |
   | --- | --- |
   | Framework Preset | `Vite` |
   | Root Directory | `./` (корень репозитория) |
   | Install Command | `npm ci` |
   | Build Command | `npm run build` |
   | Output Directory | `dist` |
   | Node.js Version | `20.x` или новее |

   Vercel обычно определяет Vite и команды автоматически, но эти значения можно задать вручную в **Build and Deployment Settings**.
5. Переменные окружения не требуются. Нажмите **Deploy** и дождитесь статуса **Ready**.
6. Откройте выданный адрес на компьютере и телефоне, нажмите **«Включить камеру»**, разрешите доступ и проверьте ввод точки, тире и открытой ладони.

После подключения GitHub каждый push в отслеживаемую ветку запускает новую сборку Vercel. Для сдачи используйте production-адрес, выданный для ветки `main`, а не временную preview-ссылку.

### Если сборка или камера не работают

- Если сборка упала, откройте вкладку **Deployments → Build Logs** и проверьте, что установлены `npm ci`, `npm run build` и Output Directory `dist`.
- Если Vercel не видит проект, убедитесь, что Root Directory — корень репозитория, а не папка `src`.
- Для веб-камеры нужен HTTPS: адрес Vercel подходит. Разрешение камеры выдаётся в настройках браузера для этого домена.
- Модели `hand_landmarker.task`, `blaze_face_short_range.tflite` и файлы WASM MediaPipe уже лежат в `public/`, поэтому дополнительных переменных окружения, API-ключей или CDN не нужно.

После успешной публикации вставьте production-адрес в это поле и в `SUBMISSION.md`:

`https://<ваш-проект>.vercel.app`
